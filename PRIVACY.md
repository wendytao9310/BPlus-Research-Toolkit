# Privacy and research-data handling

BPlus processes potentially sensitive behavioral, physiological, neuroimaging, video, and clinical data. The public repository contains no participant records.

Operators should use coded identifiers, keep identity keys separately, store data only in approved encrypted locations, avoid unapproved cloud uploads, review exports for metadata, restrict participant reports to validated non-diagnostic language, and document software/configuration/QC decisions.

The `.gitignore` excludes standard output locations, but this is not a substitute for an institutional data-management plan.
