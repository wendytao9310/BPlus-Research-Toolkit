# BPlus Research Toolkit 0.1.2

This release packages the English research-software edition for public review.

Included: localized launcher and participant screens; REST, MMN, VFT, N-back, and Emotion workflows; behavioral/event export; multimodal import; QC and unified reports; demo-safe stimuli with provenance; tests and documentation.

Excluded: participant/clinical records; generated reports and logs; virtual environments and machine paths; raw third-party archives; restricted or unverified stimulus libraries.

Boundary: this is a source distribution and local research preview. It is not yet a signed/notarized standalone macOS application, and real-device acquisition remains site-validation dependent.

Licence: original BPlus source code is available under Apache License 2.0. Stimuli and other third-party materials remain subject to their own terms.

Changes since 0.1.0: synchronized English-language regression tests, removed machine-specific fixture paths, translated the optional Streamlit dashboard, added the final repository and Release links, and normalized the complete Apache-2.0 distribution text.
