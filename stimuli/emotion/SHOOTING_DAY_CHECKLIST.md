# 拍摄当日清单（SHOOTING DAY CHECKLIST）

## 一、拍摄前一天

- [ ] 伦理批件已覆盖"刺激材料拍摄"（或已有单独的拍摄批准）
- [ ] 模特（及监护人）已收到同意书并阅读；确认到场时间
- [ ] 摄影棚/房间已预约；背景布、灯光、三脚架到位
- [ ] 相机电池充满 ×2、存储卡格式化且容量够（RAW 每人约 1–2 GB）
- [ ] 灰卡、反光板、固定注视点贴纸、卷尺（固定距离）准备
- [ ] 打印《拍摄记录表》或准备电子表格
- [ ] 打印《模特肖像使用同意书》两份（监护人 + 本人）
- [ ] 确认报酬准备（按院方流程）

## 二、到场后（模特拍摄前）

- [ ] 核对身份与年龄；未成年人确认监护人已到场或已签署
- [ ] 讲解拍摄流程、可随时叫停、负性条件说明（不隐瞒）
- [ ] **双签同意书**（本人 + 监护人）；填写同意书编号，抄入拍摄记录表
- [ ] 分配模特编号（M##），**不记录姓名到拍摄记录表**
- [ ] 造型检查：取下眼镜/饰品；头发不遮眉耳；统一深色上衣
- [ ] 固定机位：三脚架高度=眼平、距离=1.5–2.0 m、焦距固定、光圈 f/8、ISO 最低、白平衡固定

## 三、拍摄流程（每名模特）

- [ ] 拍灰卡 + 空白背景（每次换模特或换灯位都要重拍）
- [ ] **neutral**：静默 5 s → 指令 → 拍 5–8 张
- [ ] 休息 30 s
- [ ] **positive**：指令 → 拍 5–8 张（挑出自然真笑）
- [ ] 休息 30 s
- [ ] **negative**：指令（低强度）→ 拍 5–8 张 → **立即观察模特状态**，需要时停止并休息
- [ ] 每张记录：条件、序号、指令原文、模特自评强度 1–5、拍摄参数、异常备注
- [ ] 全套拍完与被试一起回看（简要），确认无不想保留的照片

## 四、拍摄后（当天）

- [ ] 素材双备份（存储卡 → 受控服务器 + 加密移动硬盘）
- [ ] 同意书扫描归档（受控目录，**不入库**）
- [ ] 拍摄记录表电子化（CSV）
- [ ] 素材整理进 `stimuli/emotion/raw/<session_date>/`（该目录已 gitignore）
- [ ] 记录当日异常（灯光漂移、设备故障、模特不适事件）

## 五、常见异常处理

| 异常 | 处理 |
| --- | --- |
| 真笑不足（只有嘴角） | 换指令（回忆具体趣事）；仍不行 → 该条件标记 `retry` |
| 眼镜反光 | 取下镜片/调整光位；仍不行 → 记录并评估是否入库 |
| 模特负性条件不适 | **立即停止**，转中性话题，休息；必要时转介；记录事件 |
| 灯位/色温漂移 | 重拍灰卡；如已拍摄大量素材 → 全部重拍（不将就） |
| 未成年人无监护人签字 | **不得拍摄**（合规红线） |
