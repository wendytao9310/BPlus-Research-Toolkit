# 自建情绪刺激：拍摄 / 委托制作规格书

**适用**：本项目正式版 Emotion 刺激（中国青少年面孔）的自主拍摄或委托拍摄。
**目标**：产出**可入库、可复现、可审计**的标准化面部刺激，通过 `emotion_library.py validate`。

---

## 0. 验收目标

| 项 | 目标值 |
| --- | --- |
| 数量 | **每条件 20–40 张**（positive / neutral / negative），pilot 淘汰后每条件仍 ≥20 |
| 平衡 | 性别 ≈ 1:1；表观年龄覆盖 12–18 岁各年龄段；表观族裔以汉族为主但含少量其他族裔；情绪强度分布 2–5 各档都有 |
| 技术 | 见 §7 门槛（尺寸/亮度/对比度/去重） |
| 合规 | 每张都有：模特同意书编号 + 伦理批件编号（写入 `manifest.csv` 的 `notes`） |

---

## 1. 模特招募

| 项 | 要求 |
| --- | --- |
| 年龄 | **12–18 岁**（表观年龄与真实年龄一致者可备注）；成年人仅作为备选并需在方法中说明 |
| 数量 | 建议 12–20 名模特 × 每人 3 条件 × 5–8 张候选 → 可筛出 60–120 张 |
| 标准 | 面部无遮挡（无浓密刘海/口罩/疤痕遮挡情绪线索）、无夸张妆容、无面部整形史、无急性皮肤问题 |
| 排除 | 不同意肖像使用、无法配合指令、有面部运动障碍 |
| **未成年人双同意** | **监护人书面同意 + 模特本人知情同意**（两者缺一不可；模板见 `MODEL_CONSENT_TEMPLATE.md`） |
| 报酬 | 按院方标准支付；金额与支付方式写入伦理申请 |
| 隐私 | 现场不公开姓名；拍摄记录用编号（如 `M07`），不写真实姓名 |
| 撤回权 | 模特（或监护人）可在**数据发布前**申请撤回；撤回后该刺激移入 `rejected/` 并记录 |

---

## 2. 设备与拍摄环境

| 项 | 规格 | 为什么要固定 |
| --- | --- | --- |
| 相机 | ≥24 MP 可换镜头相机，RAW（14 bit） | 保留后期余地 |
| 镜头 | **50–85 mm（等效 85–105 mm）**，人像焦段 | 广角会产生透视变形，改变面部结构 |
| 光圈 | **f/8**（或 f/5.6–f/8） | 保证整张脸清晰（含耳、下颌） |
| 快门 | ≥ 1/250 s | 避免微动模糊 |
| ISO | 原生最低（如 100） | 降低噪点 |
| 白平衡 | 固定（闪光灯 5500 K）+ 每场拍**灰卡** | 避免情绪刺激间的色温漂移 |
| 三脚架 | 固定机位，锁定高度与距离 | 保证跨模特、跨条件的**几何一致性** |
| 相机高度 | 与模特眼平；模特坐姿、下颌微收 | 避免俯拍/仰拍造成支配感差异 |
| 距离 | 固定 1.5–2.0 m | 与镜头焦距共同决定透视 |
| 背景 | 中性灰（≈18% 灰）或深灰布幕，无褶皱、无阴影斑 | 降低背景亮度差异对 ERP/fNIRS 的干扰 |
| 照明 | 主光 45° 侧上方 + 反光板补光；**光比 1:1.5–1:2**；无硬阴影 | 光比过大会让负性面孔显得更"威胁"，混淆情绪与光照 |
| 眼神 | 注视镜头中心（固定注视点贴纸） | 保证注视方向一致（眼动分析需要） |
| 环境 | 安静、无异味、室温稳定；拍摄全程同一时段（避免昼夜节律） | 减少非情绪变量 |

**每场必拍**：① 灰卡 ② 空白背景 ③ 每位模特的 3 个条件各 5–8 张。

---

## 3. 表情诱发脚本（标准化指令）

统一由同一名拍摄者下达指令，**指令文本固定、不加即兴提示**：

| 条件 | 指令（中文，逐字） | 备选（若无法达成） |
| --- | --- | --- |
| **positive** | "请想一件最近让你特别开心的事，想象那个画面，然后看着我，露出你自然的笑容。" | 播放一段中性幽默短句（内容需伦理备案） |
| **neutral** | "请放松面部，什么都不要想，保持平静地看着镜头。"（拍摄前静默 5 s） | — |
| **negative** | "请想一件让你难过的事（不必说出是什么），保持这个感受看着我。" | 播放一段低唤醒的悲伤音乐片段（需备案） |

**关键纪律**：
1. **不使用任何可能诱发强烈痛苦的指令**（例如"想象亲人去世"），负性指令必须是低强度、可撤回的；
2. 每张拍完后让模特**自评情绪强度 1–5**，录入拍摄记录表；
3. 每条件至少 5 张候选，拍摄者可提示"再自然一点/再淡一点"，但不诱导极端表情；
4. 若模特在负性条件中出现明显不适 → **立即停止**，记录事件，并考虑是否继续（与 `AGE_CULTURAL_ETHICS.md` §三 一致）。

---

## 4. 造型与一致性

- 服装：统一无图案的深色（黑/深灰）上衣；不得出现 logo、文字、条纹（避免视觉诱发）。
- 头发：不遮眉毛与耳朵；不遮挡额部（fNIRS 光极区域无关，但影响情绪识别）。
- 饰品：全部取下（眼镜、耳环、鼻钉、发卡）；**眼镜反光必须避免**（如必须佩戴，需记录并在后期评估）。
- 化妆：允许自然妆；不得改变面部结构（不画夸张眼线/唇形）。
- 表情肌状态：同一模特三条件之间休息 ≥30 s。

---

## 5. 命名与记录

**文件命名**（原始）：`M##_<condition>_<seq>.raw`
例：`M07_positive_03.CR3`

**交付命名**（处理后）：`<condition>_<model>_<seq>.png`
例：`positive_M07_03.png`

**拍摄记录表**（CSV，必填字段）：

| 字段 | 说明 |
| --- | --- |
| model_id | 编号（M01…），不含姓名 |
| condition | positive / neutral / negative |
| seq | 该条件第几张 |
| instruction_used | 实际使用的指令（逐字） |
| self_rated_intensity | 模特自评强度 1–5 |
| shutter/aperture/iso | 拍摄参数（确认未漂移） |
| grey_card_shot | 本场是否有灰卡（是/否） |
| timestamp | 拍摄时间 |
| consent_id / ethics_id | 同意书编号 / 伦理批件编号 |
| issues | 眼镜反光、头发遮挡、真笑不足等 |

## 6. 后期标准化（→ `processed/`）

| 步骤 | 规格 |
| --- | --- |
| 裁切对齐 | 以**瞳距**为基准归一化：裁切后双眼水平、瞳距占画面宽度 **28–32%**；面部中线居中 |
| 尺寸 | 统一 **1000 × 1000 px**（正方形），头部占画面高度 70–80% |
| 色彩 | 保留彩色版 + 生成灰度版（`*_gray.png`）；灰度用 Rec.709 亮度 |
| 亮度归一化 | **均值 0.45–0.55**（0–1 尺度），跨刺激标准差 ≤0.05 |
| 对比度 | RMS 对比度 ≥0.05，且跨刺激差异 ≤0.03 |
| 去伪影 | 去水印/文字/边框；不做美颜（不改变面部结构）；不做锐化 |
| 去标识 | 文件名与 EXIF 中**不得**含姓名；EXIF 全部剥离（保留拍摄日期可选） |
| 保留原始 | `raw/` 保存原始 RAW/JPEG；`processed/` 只放标准化版本 |

---

## 7. 技术 QC 门槛（与代码一致）

`python scripts/emotion_library.py qc` 会逐张检查：

| 指标 | 门槛 | 不达标处理 |
| --- | --- | --- |
| 尺寸 | ≥256 × 256 px | 重新裁切 |
| 亮度均值 | 0.15–0.90 | 亮度归一化后重跑 |
| 对比度 RMS | ≥0.03 | 重拍或重做 |
| 感知哈希去重 | aHash 距离 ≤4 视为重复 | 保留更优者，另一张移入 `rejected/` |
| SHA256 | 必填 | 脚本自动生成 |
| 人工清单 | 见 `AGE_CULTURAL_ETHICS.md` §一（13 条） | 不通过 → `rejected/` |

## 8. 交付物与合同要点

**交付物清单**：
1. `raw/` 原始文件（含灰卡与空白背景）
2. `processed/` 标准化刺激（PNG，彩色 + 灰度）
3. 拍摄记录表 CSV
4. 模特同意书原件扫描件（另存于受控目录，**不入库**）
5. 技术 QC 报告（`library_validation.json`）

**委托拍摄合同的必备条款**：
- **著作权归属**：明确约定刺激的著作权归**本研究的医院/研究机构**所有（或授予永久、不可撤销、可转授的科研使用权）；
- **使用范围**：仅用于本研究及其成果发表；不得用于广告、商业、AI 训练等其他用途（如需 AI 训练须单独授权）；
- **再分发**：允许在论文补充材料/公开数据集中发布**处理后**的刺激（若模型仅授权科研使用，则改为"仅限受控共享"）；
- **撤回条款**：模特（或监护人）在成果发布前可撤回同意，撤回后刺激停止使用并下架；
- **未成年人条款**：监护人签署 + 模特本人签署；注明报酬与用途；
- **保密与数据安全**：原始文件仅存于受控服务器，不得上传公有云；
- **违约与争议解决**：按院方合同模板。

## 9. 常见坑（务必避免）

| 坑 | 后果 | 预防 |
| --- | --- | --- |
| 用广角近拍 | 面部透视变形，情绪强度被放大 | 85 mm 等效焦段 + ≥1.5 m |
| 光比过大 | 负性面孔被"光照"污染 | 光比 1:1.5–1:2，反光板补光 |
| 眼镜反光/框架遮挡 | 眼动与情绪识别异常 | 拍摄前检查，必要时取下镜片 |
| 假笑（only mouth） | 效价评分偏低、一致性差 | 用"想象开心事"指令 + 允许重拍 |
| 头发遮眉 | 眉部是情绪识别的关键区域 | 造型统一要求 |
| 色温漂移 | 跨刺激亮度/色差 | 每场灰卡 + 固定白平衡 |
| 模特间几何差异 | 跨刺激视觉突变 | 三脚架固定 + 瞳距归一化 |
| 只拍一版 | pilot 淘汰后不足 20 张 | 每条件 5–8 张候选 |
| 忘了同意书编号 | 无法溯源，闸门不放行 | 拍摄记录表强制字段 |
