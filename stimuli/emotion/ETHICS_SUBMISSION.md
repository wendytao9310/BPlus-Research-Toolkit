# 伦理送审说明：刺激材料部分（可直接粘贴的写法）

**用途**：提交医院/学校伦理委员会时，用于说明 Emotion 范式的刺激材料（来源、内容、适配、风险与保护措施）。
**配套附件**：`stimulus_sources.csv`、`manifest.csv`、contact sheet、`PILOT_PROTOCOL.md`、`MODEL_CONSENT_TEMPLATE.md`、样例刺激 6 张。

## 一、可直接粘贴的正文（中文）

### （一）刺激材料的来源与构成

本研究拟使用三类情绪面孔刺激（正性 / 中性 / 负性），共 **N** 张（每类 N/3 张）。
刺激来源为：☐ 本研究自行拍摄（委托拍摄，见《拍摄规格书》）；☐ 公开标准化刺激库（库名、授权状态与原文条款见附件《刺激材料来源与授权清单》）。
若使用公开库，我方已逐库核对授权范围，仅使用**允许科学研究和本地保存**的库；对**禁止再分发**的库（如 KDEF），材料仅保存在受控服务器，不进入公开代码仓库、论文补充材料或任何公网位置。
所有刺激的版权与使用许可文件已归档，编号为 ______。

### （二）选用依据

青少年抑郁研究中使用面孔情绪刺激，主要用于考察**情绪加工（识别、效价/唤醒度评价）与前额叶血氧反应**。本研究选用面孔（而非场景图片）的理由是：① 面孔情绪加工有较强的临床相关性；② 与本研究同时采集的眼动指标（注视分布）匹配；③ 便于与既往青少年抑郁研究结果可比。
每张刺激的诱发条件（正/中/负）与情绪强度，均经过**预实验（见附件《刺激预实验方案》）**由目标人群同龄评定者评分确认，未通过门槛的刺激将被剔除。

### （三）内容与年龄、文化适配

1. **内容筛查**：所有刺激已逐张审核，**不含**暴力、血腥、色情、自伤、恐怖、儿童不适宜内容；不含文字水印与品牌标识（清单见附件 `AGE_CULTURAL_ETHICS.md` 的 13 条清单）。
2. **年龄适配**：刺激面孔的表观年龄与本研究对象（12–18 岁）匹配；若使用成人面孔库，已在方法中说明局限。
3. **文化适配**：优先使用中国青少年面孔；已避免依赖特定文化符号的素材。理论上，面孔加工存在同族效应（own-race bias），使用与研究对象同族同年龄段的面孔可提高生态效度。
4. **强度控制**：负性刺激为**低至中等强度**（预实验中强度评分上限受控），不包含可能引起强烈痛苦的内容。

### （四）风险与最小化措施

本研究情绪范式的风险级别为**不大于日常生活经验**（图片观看），主要风险为偶发的不适或短暂情绪波动。措施：

1. **事前告知**：进入情绪任务前，被试（及其监护人）被告知可随时停止、可跳过任一图片；
2. **随时中止**：被试可口头说"停"、按 ESC，或由操作员随时中止；中止立即停止刺激并转入中性任务（如静息）；
3. **负性刺激限量**：负性刺激数量与时长受限（见 protocol），且块间设有恢复间隔；
4. **临床把关**：全部负性刺激由临床人员审阅（`clinical_review` 字段）；对被试在访谈中已报告明显痛苦者，可按预案**跳过负性条件**并记录为方案偏离；
5. **事后关怀**：任务结束后进行情绪恢复（中性/正性内容或静息），由访谈者评估被试状态；如需要，转介临床随访；
6. **人员资质**：负性刺激呈现期间，访谈者/临床人员在场或可立即到场。

### （五）数据、隐私与未成年人保护

1. 刺激材料相关数据（评分、注视、脑信号）与身份信息**分离存储**；
2. 被拍摄的模特（若自建刺激）与参与实验的被试**为不同人群**；模特签署专门的**肖像使用同意书**（未成年人由监护人 + 本人双签），同意书原件存受控档案，不进入研究数据集；
3. 所有刺激文件不含姓名，EXIF 已剥除；原始素材仅存受控服务器，访问需授权与登记；
4. 数据保存期限 ______ 年，到期销毁；发表时仅使用标准化后的刺激，且遵守各来源的授权条款。

## 三、伦理委员会常见追问与标准回答

| 追问 | 回答要点 |
| --- | --- |
| "这些图片从哪来？有版权吗？" | 出示 `stimulus_sources.csv` 的授权原文与 `LICENSES.md` 的结论；禁止再分发的库说明存放位置与访问控制 |
| "会不会让抑郁青少年更难受？" | 负性刺激为低–中强度、数量受限；事前告知 + 随时中止 + 事后恢复 + 临床人员在岗；引出明显不适的比例在预实验中受控（≤10%） |
| "为什么不用现成的国际库？" | 说明同族效应与年龄匹配：优先中国青少年面孔；国际库（如 KDEF/FACES）作为方法学对照或备选，并遵守其再分发限制 |
| "怎么保证刺激之间可比？" | 拍摄规格书（固定焦段/光比/背景/几何归一化）+ 亮度对比度归一化 + 预实验效价/唤醒度均衡 |
| "未成年被拍摄者的保护？" | 监护人+本人双同意、可撤回、限于科研用途、不公开原始素材、报酬按院方标准 |
| "如果中途想换刺激怎么办？" | 变更管理：替换刺激需提交修正案，并重跑 `emotion_library.py validate`（REAL MODE 会再次锁定） |

## 四、变更管理（重要）

伦理批件批准的是**具体的刺激集**。因此：

1. 任何刺激的**增删改**都要：更新 `manifest.csv` → 重跑 `qc` → 重跑 `validate` → 如已获批则提交伦理修正案；
2. `manifest.csv` 的 `version` 字段随每次变更递增（例：`v1.0` → `v1.1`）；
3. 系统层面：**刺激库版本变化会使 REAL MODE 自动回到 DISABLED**（因为 `VALIDATION_REPORT.md` 需重新标记 `STATUS: COMPLETE`），必须重新走一遍审核。
