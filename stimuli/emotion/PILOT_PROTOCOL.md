# 情绪刺激预实验方案（PILOT_PROTOCOL）

目的：在**正式被试**之前，确认刺激材料的效价/唤醒度、可识别性、年龄与文化适配性，以及临床可接受性。
（本文件的存在是 REAL MODE 闸门的一个条件；**内容必须按本方案真正执行后才允许标记完成**。）

## 1. 设计

| 项 | 设定 |
| --- | --- |
| 评定者 | 健康青少年（与目标人群同龄，≥20 人）+ 临床人员（≥2 人） |
| 评定对象 | 全部候选刺激（正式版建议每条件 20–40 张，去掉被否决的） |
| 维度 | 效价（1–5，1=非常不愉快）、唤醒度（1–5，1=非常平静）、情绪类别（正/中/负）、**强度（1–5）**、清晰度（1–5）、年龄观感、文化熟悉度（1–5）、是否引起不适（是/否） |
| 呈现 | 与正式实验一致的时长（3 s）与视角；随机顺序；允许跳过 |
| 时长 | 约 25–30 分钟（含休息与知情同意） |

## 2. 判定标准（写入 manifest 前的门槛）

| 指标 | 门槛 | 不达标处理 |
| --- | --- | --- |
| 情绪归类一致性 | ≥80% 评定者归入预期条件 | 移入 `rejected/` 或降低强度后重评 |
| 平均效价 | positive ≥3.5；neutral 2.5–3.5；negative ≤2.5 | 调整或淘汰 |
| 平均唤醒度 | 三类之间需有可区分差异（配对比较 P<0.05） | 调整或淘汰 |
| 清晰度均值 | ≥4.0 | 换图 |
| 引起不适比例 | negative 条件 ≤10%，且无人报告明显痛苦 | 临床复核；必要时淘汰 |
| 年龄观感 | 与目标人群差距可接受（需记录） | 说明或替换 |

## 3. 记录与归档

- 逐张刺激的评定结果 → `stimulus_audit.csv`（增加评定列后另存 `pilot_ratings.csv`）
- 结论 → 更新 `manifest.csv` 的 `age_suitability` / `cultural_suitability` / `clinical_review`
- 报告 → `VALIDATION_REPORT.md` 增加"Pilot 结果"章节，并标记 `STATUS: COMPLETE`
- 伦理：pilot 本身也需要伦理审批（或纳入主批件的"刺激预实验"范围）

## 4. 完成后必须做的事

1. 把通过 pilot 的刺激移入 `processed/`（统一尺寸、灰度/色彩空间、亮度与对比度归一化，并重新计算 SHA256）；
2. 重跑 `python scripts/emotion_library.py qc && python scripts/emotion_library.py validate`；
3. 由临床团队签署 `CLINICAL_APPROVAL.md`（内容需包含 `APPROVED` 字样）；
4. 此时 REAL MODE 才会自动变为 ENABLED。
