# 年龄 / 文化 / 伦理审核清单（AGE_CULTURAL_ETHICS）

每张进入正式刺激库的图片都必须逐项打勾，并把结论写回 `manifest.csv` 的对应列
（`age_suitability` / `cultural_suitability` / `ethics_status` / `clinical_review`）。
**只有值恰好为 `YES` 才被闸门接受**（`YES_SYNTHETIC_ONLY`、`PENDING` 等都不算通过）。

## 一、逐张图片检查清单（§43）

```
[ ] 不包含儿童不适宜内容
[ ] 无暴力
[ ] 无血腥
[ ] 无色情
[ ] 无自伤内容
[ ] 无明显恐怖刺激
[ ] 面部清晰（无遮挡、无重度模糊）
[ ] 情绪表达明确（≥2 名评定者一致）
[ ] 年龄适配（看上去像青少年/同龄人，或明确标注为成人面孔并说明理由）
[ ] 文化适配（中国青少年可识别；无强烈西方文化符号依赖）
[ ] 无明显视觉伪影（压缩块、水印、边框、文字）
[ ] 版权明确（`license_status` 属于允许状态）
[ ] 伦理状态明确（伦理批件编号或"仅示意图"标注）
```

## 二、中国青少年适配的专门要求（§6）

1. **不能直接假设"西方成人面孔 = 中国青少年刺激"**：面孔识别存在同族效应（own-race bias）。
2. 记录并尽量平衡：性别、表观年龄、表观民族、情绪强度。
3. 表观年龄：优先 12–18 岁观感；若用成人库（如 FACES/KDEF），必须在方法与局限中写明。
4. 文化适配：避免依赖特定文化符号（节日、宗教、特定影视角色）。
5. 中文语境下的情绪词与面孔一致性：正式 pilot 需让评定者用中文效价/唤醒度评分（见 `PILOT_PROTOCOL.md`）。

## 三、临床敏感性与安全（§44–§45）

研究对象包含 **青少年抑郁**，因此：

| 项 | 要求 |
| --- | --- |
| `clinical_review` | 每张负性刺激必须由临床人员审阅并标记 `YES`；若可能诱发明显不适 → `REQUIRES_CLINICAL_REVIEW`（闸门不放行） |
| 事前告知 | Emotion 区块开始前，被试必须被告知"如果感到不舒服，可以随时停止" |
| 退出机制 | 程序必须支持 `ESC` / 操作员中止 / 被试口头要求中止 |
| 中止记录 | 每次中止都要写入 `emotion_abort`（理由 + 时间戳），并通知访谈者 |
| 不追加负性刺激 | 若被试已在访谈中报告明显痛苦，操作员可跳过 Emotion 的负性条件（需记录为 protocol deviation） |

## 四、审核流程

```
素材 → 技术 QC（scripts/emotion_library.py qc）
     → 生成 contact sheet（scripts/emotion_library.py contacts）
     → 2 名研究者独立逐项打勾（本文件清单）
     → 临床人员审阅负性刺激
     → 结论写回 manifest.csv
     → python scripts/emotion_library.py validate
```

冲突处理：两名评定者结论不一致 → 第三名评定者裁决；仍不一致 → 该刺激移入 `rejected/` 并记录原因。
