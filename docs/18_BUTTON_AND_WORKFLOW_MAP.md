# BPlus 按钮与工作流程说明

## 正式操作主线

```text
填写被试与会话信息
        ↓
选择范式 → 检查设备与环境（可单独运行）
        ↓
确认信息并开始实验（内部会再执行一次预检）
        ↓
行为学数据自动保存
        ↓
打开多模态数据中心
        ↓
将同一 participant_id + session_id 的 EEG / fNIRS / 行为学整包分类暂存
        ↓
统一分析并生成完整报告
        ↓
打开本次完整报告 / 导出论文行为数据
```

## 主界面按钮关系

| 区域 | 按钮 | 是否改变数据 | 前置条件 | 输出/后续 |
|---|---|---:|---|---|
| 1 采集实验 | 检查设备与环境 | 否（只写预检记录） | 至少选一个范式 | PASS 后可开始实验 |
| 1 采集实验 | 确认信息并开始实验 | 是 | 被试/会话、范式、预检 | 刺激、事件、行为 CSV、阶段报告 |
| 1 采集实验 | 查看本次行为反应 | 否 | 已有行为 CSV | 显示按键、RT、效价和唤醒评分 |
| 2 导入与分析 | 打开多模态数据中心 | 是（仅暂存） | 被试/会话 | 分类导入整包，导入时不分析 |
| 2 导入与分析 | 统一分析并生成完整报告 | 是 | 至少一类数据已暂存、有审核人 | 一次性分析/QC/归并和报告 |
| 2 导入与分析 | 导出论文行为数据 | 是（新建导出包） | 已有行为 CSV | trial CSV、BIDS events.tsv、字典、QC、ZIP |
| 2 导入与分析 | 补充临床/心理资料 | 是 | 已有多模态 JSON 分析包 | 生成可追溯的临床补充版本 |
| 3 查看结果 | 打开本次完整报告 | 否 | 报告已生成 | 只打开，不会偷偷重新生成部分报告 |

## 已去除的主界面重复

- “生成被试报告”只生成行为学待分析报告，不是完整报告；已从可见界面下线。
- “导入完整多模态分析包”是旧 JSON 工作流；已移入高级工具。
- “运行数据分析”是要求逐个导入 MMN/VFT NPZ 的历史流程；已从所有可见界面下线，仅保留底层代码供旧数据迁移时使用。
- “统一分析并生成完整报告”只保留在数据中心，避免主界面和子窗口出现两个相同入口。
- 开发者自动测试不再与正式实验按钮并列。

## 安全边界

- DEMO/VISUAL_DEMO 成功只证明软件流程可运行。
- REAL 运行前仍需物理 TTL、EEG、fNIRS 与同步证据。
- 报告中的“当前状态”是研究性描述，不是临床诊断。

## 被试键盘按键

| 键 | 生效阶段 | 作用 | 是否冲突 |
|---|---|---|---|
| `S` | 每个范式的30秒说明页 | 被试已准备好，提前进入3、2、1倒计时 | 无；正式试次中不作为反应键 |
| `T` | 说明、倒计时、正式试次和情绪评分 | 安全中止当前范式 | 无；是全局中止键，不计为任务反应 |
| `Enter/Return` | N-back 数字反应窗 | 看到0-back目标数字，或当前数字与前两个数字相同时作答 | 无；其他范式不用 Enter 记分 |
| `1`–`5` | Emotion 块末评分页 | 先评愉快程度，再评激动程度；主键盘和小键盘均支持 | 无；只在评分页监听 |

目前这四组键通过“页面/时间窗”隔离，没有同一时刻的功能重复。
