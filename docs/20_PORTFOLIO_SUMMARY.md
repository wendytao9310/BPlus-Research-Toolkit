# Portfolio summary

**BPlus Research Toolkit** is an English-language, open research-software preview for multimodal adolescent mental-health experiments. It combines five cognitive and affective paradigms with session-linked behavioral records, EEG/fNIRS-oriented event markers, staged multimodal import, quality control, and one consolidated research report.

The project demonstrates product thinking across the full research workflow: participant/session identity, acquisition UX, reproducible event definitions, modality-specific QC, provenance-aware data integration, research-facing export, and explicit clinical-safety boundaries.

## What reviewers can inspect

- Experiment launcher and participant workflow
- Rest, auditory MMN, verbal fluency, N-back, and emotion task implementations
- Trial-level response and marker exports
- EEG, fNIRS, behavioral, eye-tracking, physiology, and clinical import architecture
- Unified report generation with missing-data disclosure
- Automated source tests and frozen-application smoke testing

## Honest scope

This release is a research-tool preview, not a medical device. Software validation is documented separately from real-hardware, ethics, and clinical validation. The repository contains no participant data and the included demonstration stimuli must not be treated as a validated adolescent clinical stimulus set.
