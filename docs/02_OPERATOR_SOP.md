# Operator SOP

1. 确认知情同意与被试编号。
2. 双击 **BPlus Experiment**。
3. 输入 Participant ID、Session ID、Operator。
4. 选择范式和模式：DEMO 是无画面快速自检；VISUAL_DEMO 是有画面、模拟触发的短演示；正式采集只能选 REAL。
5. 点击 **Device / Preflight Check**。
6. 任一红色 FAIL 时不得开始；保存并通知开发人员。
7. 完成 EEG 阻抗、fNIRS 信号、眼动校准和同步脉冲检查。
8. 点击 **Start Experiment**，期间不切换窗口、不运行其他软件。
9. 看到 `Session completed successfully` 后确认行为和触发日志存在。
10. 运行实验后 QC，并按研究方案备份原始数据。
