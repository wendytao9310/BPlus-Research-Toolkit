# Grace Quick Start

只记住四件事：

1. 双击 `BPlus Experiment`。
2. 填写被试和会话编号。
3. 只检查数据链路选 `DEMO`；要观看实验画面选 `VISUAL_DEMO`，并建议一次只勾选一个范式。
4. 点击预检；只有全部通过才能开始。
5. 点击 Start Experiment；第一次打开 PsychoPy 画面可能需要约 20–30 秒。
6. 结束后必须看到绿色的 `Session completed successfully`。

不要改代码、marker、配置或手动移动 session 文件。出现 FAIL 时截图并记录被试编号、时间和失败项目。
