# 被试交互与反应记录

## 操作流程

1. 操作员填写被试编号、访视/会话编号和操作员。
2. 每个范式首先显示最多 30 秒的说明画面。
3. 被试准备好后按 `S`，随后出现 `3 → 2 → 1` 倒计时。
4. 范式正式计时从倒计时结束后开始；说明和倒计时不计入正式范式时长。
5. 被试可在说明、倒计时或范式运行期间按 `T` 安全中止。

## Emotion 评分

- 每个区块结束后先选择愉快程度 `1–5`，屏幕立即显示已记录的数字。
- 随后选择激动程度 `1–5`，屏幕再次显示已记录的数字。
- 最后显示本组两项评分摘要。
- CSV 分别保存 `valence`、`arousal`，同时在 `key` 字段保存如 `valence=3;arousal=4` 的审计文本。

## 反应记录位置

行为记录位于：

`data/session/sub-<被试编号>_ses-<会话编号>_<范式>_behavior.csv`

启动器中的“查看被试反应”会读取当前被试和会话的全部行为 CSV，显示按键、反应时、愉快程度和激动程度。

## 正式方案时长

正式模式不压缩配置时间；VISUAL_DEMO 使用 35% 时间轴，仅用于培训。

| 范式 | 配置时长 |
| --- | ---: |
| Rest | 180 秒 |
| MMN | 365 秒 |
| VFT | 165 秒 |
| N-back | 384 秒 |
| Emotion | 约 252 秒（抖动 ITI 会造成小幅变化） |
| Recovery | 120 秒 |

MMN、VFT、N-back、Emotion 合计约 1166 秒，加 lead-in 与范式间隔后位于方案的 1200 秒计算机范式阶段内。

## MMN 音频

- 标准音：`stimuli/audio/mmn/tone_1000Hz_100ms.wav`
- 偏差音：`stimuli/audio/mmn/tone_2000Hz_100ms.wav`
- 16-bit mono、44.1 kHz、5 ms 升降沿。
- 正式采集前仍必须在目标实验机做声压校准、实际输出延迟测量和 EEG 收码验证。
